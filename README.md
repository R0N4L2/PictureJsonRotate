# PictureJsonRotate — rotación de coordenadas en datos de imágenes

**En una frase:** análisis estadístico y rotación de datos geométricos (JSON) asociados a imágenes, para corregir su orientación.

## Contenido
- `Rotacion.ipynb` — método de rotación y verificación.
- `json270grado.json` → `json270grado_rotated.json` — ejemplo de entrada y salida.
- `ejemplos/` — casos de ejemplo.

## Tecnologías
Python · Jupyter · JSON
